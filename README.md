## 一、代码技术

纯静态，不依赖任何框架或构建工具。  
HTML + CSS + JavaScript，原生手写，连 `package.json` 都省了。

- **HTML**：语义化标签，结构清晰到连你也看得懂。
- **CSS**：
  - 用 CSS 自定义属性管理颜色，内置亮色（默认）和暗黑两套主题。
  - 暗黑模式下页脚和关键说明段落单独提亮，以防你眯着眼睛找。
- **JavaScript**：
  - 中英文切换、主题切换、复制按钮——功能刚好够用，不多不少。
- **静态资源**：下载链接指向 `download/` 目录或外部网盘，不需要后端。

> 非要问为什么不用 Vue？——因为没必要。加载速度 0.3 秒，随你测。

1. **联机方案指引**  
   列出 ZeroTier 和 Astral 的下载链接、备用网盘、Network ID / 房间码，帮你快速组网。

   底部附 Qiuym 的 GitHub 主页，方便你逛仓库。

> 如果你不属于这三类，嗯……也不是不能看，但可能找不到你想找的东西。

## 三、部署与访问

采用 GitHub Pages + Cloudflare Pages 双平台部署，国内外访问都还算稳。

### 在线地址

- **GitHub Pages**  
  `https://qym1421.github.io`

- **Cloudflare Pages**  
  `https://qym1421.pages.dev`  

两个地址内容一样，挑一个顺眼的用就行。

### 自动部署流程

- 代码在 GitHub 上，分支 `master`。
- 每次 `git push` 后，两个平台都会自动拉取并重新部署，1～2 分钟生效。

### 技术选型

- 版本控制：Git + GitHub
- 托管：GitHub Pages（零配置）、Cloudflare Pages（通过 Git 连接）
- 持续部署：全自动，不用你操心
- 域名：直接用平台给的免费二级域名，省去 DNS 和证书的麻烦
